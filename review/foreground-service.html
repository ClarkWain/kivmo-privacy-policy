User-initiated focus and break timer

Genuine screen recording of Kivmo: Focus & Tasks 1.0 (version code 17), package com.livehere.focus, on an isolated Android 16 emulator. There are no real user accounts or personal records in this demonstration.

  1. The user taps Start focus to begin a 25-minute countdown.
  2. The user returns to Android home. The ongoing notification shows the active timer while the app is in the background.
  3. The user taps Pause in the notification, then returns to the app to verify the paused session.
  4. The user stops the focus session, starts the optional break, then ends the break. The app returns to its idle state.

The foreground service supports this continuous, user-visible offline timer. A delayed start would measure the wrong period; system interruption can delay completion alerts and interrupt live timer controls. Users can pause or stop the session. The service ends when the timer returns to idle.

This video demonstrates the release app directly. English captions describe the actions; no app screens or interactions are simulated. The Android system UI remains in its emulator locale.
