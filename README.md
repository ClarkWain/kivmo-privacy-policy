# Kivmo Privacy Policy

Public privacy information and Google Play review demonstration for Kivmo: Focus & Tasks by ComfyLife.

No application source code, credentials or real user data are included. The timer demonstration under review/ uses an isolated emulator running the signed release app.

## iOS privacy and support

The iPhone/iPad-specific policy and support contact are available at [/ios/](https://clarkwain.github.io/kivmo-privacy-policy/ios/), with a [Chinese translation](https://clarkwain.github.io/kivmo-privacy-policy/ios/zh-CN.html). These pages describe the iOS app’s offline processing and platform permissions.
